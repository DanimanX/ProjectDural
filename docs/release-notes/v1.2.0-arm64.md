## ProjectDural v1.2.0-arm64 — Vulkan build no longer renders upside down

The standalone Vulkan runtime (`vf2-vulkan.aarch64`, `ProjectDural-Vulkan-aarch64.zip`) drew the
whole game vertically mirrored: the attract mode, the fighters, the sky and the 2D overlays ("PUSH
START BUTTON", "© SEGA 1994") all appeared head over heels. This release fixes it.

### What was wrong

`platform/arm64/gpu_vulkan.cpp` composites the picture itself: the backdrop, `mid`, `top` and
`side` layers and the 3D compute target are each drawn as a textured quad by a precompiled SPIR-V
shader, which lays its corners out as `dst + corner * dst_size` for both the clip-space position
and the texture coordinate. `px_to_ndc()` — the display-pixel (top-left origin, +Y down) to
clip-space conversion — mapped `py = 0` (the top row of the picture) onto `y = -1`, but SDL_GPU's
NDC has **+Y up** (`SDL_gpu.h`, Coordinate System). Every layer therefore landed mirrored about the
middle of the screen. The menus were unaffected because Dear ImGui builds its own projection.

### The fix

Two lines in `platform/arm64/gpu_vulkan.cpp`, and the reasoning is in the comments beside them:

- `px_to_ndc()` now emits the *bottom* edge of the rectangle (`1 - (py + ph) / dh * 2`), so the
  rectangle's top edge reaches the top of the screen.
- The per-quad uniform pushes `src_v + src_vh` with a **negative** height, so texture row 0 (the
  picture's top) sits on the quad's upper edge. Flipping the rectangle alone was not enough: the
  sampler would still walk the texture upwards.

Verified by running the rebuilt binary under Wayland and capturing the frame: text upright, sky
above, floor below, and the 3D target aligned with the 2D layers. The ImGui ROM-required dialog
still renders upright (it never used this path).

### Unchanged

Nothing else: no emulation, audio, input, netplay or shader changes. The OpenGL ES 2.0 PortMaster
build (`vf2.aarch64` / `ProjectDural-PortMaster-aarch64.zip`) never had this bug — it maps to NDC
in its own vertex shader — so it is rebuilt unchanged from the same source. Zero ROMs and zero game
code.
