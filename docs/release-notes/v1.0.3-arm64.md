## ProjectDural v1.0.3-arm64 — TrimUI Smart Pro support: 35 → 55 FPS

This release is about one hardware bug that had nothing to do with the GPU, plus the
instrumentation that found it.

### TrimUI Smart Pro (Allwinner A133P / PowerVR GE8300) now runs at speed

- **Measured on retail hardware, real fights:** median **49.9 FPS** (p90 53.6, peak 55.7) on
  Spruce's own CPU policy, and median **53.8 FPS** (p90 57.4, peak **57.4**) with the CPU
  pinned to `performance` at 2.0 GHz. Before this release the same console sat at a **34.9 FPS**
  median.
- **Cause:** Spruce's CPU Mode was `Powersave`, which deliberately hot-unplugs cores 1–2
  (`DEVICE_MIN_CORES_ONLINE=03`). The port pins four threads by role (main / emulation /
  sound / audio); a pin to an offline core failed with `EINVAL`, the error was dropped, and all
  four threads kept the affinity they inherited — the whole "4-core pipeline" ran on core 0.
- **Fix, in two places:** the binary resolves every role against the cores actually online and
  says which core each thread got; the launcher starts cores 1–2 for the session, puts back
  offline the ones it started, and restores the governor and the sysfs file modes on exit.

### Also in this release

- **Render Scale** (100/85/75/60/50 %) in Menu → Display, drawn off-screen and blitted up.
  Measured on the GE8300: no gain there (it is not fill-rate bound), so the default stays 100 %.
- **PowerVR-aware scissor handling:** one band scissor for the 3D pass instead of one per
  polygon on tile-based GPUs, detected from the renderer string. Also no measured gain on this
  hardware; it is kept because it costs nothing and is right for the architecture.
- **Diagnostics you can act on:** every `[perf]` line now carries `cpu=`, `scale=`, `scissor=`,
  `upl=` (2D texture upload) and `sub=` (draw submission), and the launcher logs a `[sys]` line
  with per-core clock and governor, free memory and load. `--bench-gles N` runs a ROM-free,
  deterministic render benchmark.
- **Launcher:** stops trusting `[ -w ]` on the cpufreq nodes — as root it reports true while the
  write is still refused, because those files keep mode 0444. It chmods them open as Spruce
  itself does, then verifies the governor actually took.

### Unchanged

Anbernic RG34XX (Allwinner H700 / Mali-G31) still holds its native **57.52 FPS**, as does the
Powkiddy RGB30 (RK3566 / Mali-G52) — this release does not touch the rendering path they use.
Zero ROMs and zero game code, as always.
