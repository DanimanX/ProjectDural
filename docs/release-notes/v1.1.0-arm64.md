## ProjectDural v1.1.0-arm64 — Standalone Vulkan (`SDL_GPU` SPIR-V) Runtime

This release adds a second standalone, ROM-free AArch64 binary (**`vf2-vulkan.aarch64`**, packaged as `ProjectDural-Vulkan-aarch64.zip`) alongside the existing OpenGL ES 2.0 PortMaster build (`ProjectDural-PortMaster-aarch64.zip`).

### What's new

- **Standalone AArch64 Vulkan runtime (`vf2-vulkan.aarch64`):** built with static **SDL3 (`SDL_GPU` Vulkan + SPIR-V compute shaders)**, Dear ImGui `SDL_GPU3`, SLJIT ARM64, and static `zlib` / `libc++` (`max GLIBC_2.27`, zero `libstdc++.so` / `libSDL3.so` / `libz.so` dependency). `libvulkan.so.1`, Wayland, X11, KMSDRM, and PipeWire / PulseAudio / ALSA are loaded dynamically at runtime via `dlopen`.
- **Pixel-exact Model 2A 3D + 2D composition:** delegates 3D polygon rasterization to `src/gpu/gpu3d_sdlgpu.cpp` SPIR-V compute shaders and composites System 24 2D layers (`backdrop`, `mid`, `top`, `sides`) directly on the Vulkan swapchain.
- **Measured on OnePlus Pad Pro** (Qualcomm SM8650 / Adreno 750 / Mesa Turnip 26.3.1, Arch Linux ARM, Wayland + PipeWire):
  - Live gameplay (`vf2.zip`): **120.0 FPS** (display-capped; `emu=4.82 ms`, `snd=4.54 ms`, `vulkan=0.52 ms` @ 1532 polys).
  - `--bench-gles 120` (1500 polys, `100%` scale): **1788.0 FPS** (`0.56 ms/frame`).
  - `--bench-frames 180` (headless SLJIT): **271.01 FPS**.

### Unchanged

The OpenGL ES 2.0 PortMaster build (`vf2.aarch64` / `ProjectDural-PortMaster-aarch64.zip`) for Anbernic RG34XX, Powkiddy RGB30, and TrimUI Smart Pro remains unchanged. Zero ROMs and zero game code.
